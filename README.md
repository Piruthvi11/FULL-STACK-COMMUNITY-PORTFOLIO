## 📱 Responsiveness & Viewports Tested

The website is designed mobile-first and tested for smooth rendering across all screen widths without horizontal scrolling or text overflow:

- **320px – 425px**: Mobile devices (full-width stacked cards, stacked action buttons, pure CSS hamburger menu).
- **768px**: Tablets & iPads (2-column grids, balanced spacing).
- **1024px**: Laptops & Desktops (3-column project grids, 2-column hero and about sections).
- **1440px – 1920px**: Large monitors (centered container with max-width `1140px` to maintain optimal line-lengths and visual balance).

## 🖼️ How to Add or Replace Your Images

Place your actual image files directly inside the `images/` directory with the following filenames:

1. **Profile Picture**: Replace `images/profile.jpg` with a square or portrait photo.
2. **Project 1 (Murugesh Maligai)**: Replace `images/project1.jpg` (recommended aspect ratio: 16:9, e.g., 800×450px).
3. **Project 2 (Nostra)**: Replace `images/project2.jpg` (recommended aspect ratio: 16:9).
4. **Project 3 (EHR Clinical Portal)**: Replace `images/project3.jpg` (recommended aspect ratio: 16:9).

> *Note: If an image file is not present or loading, the website automatically displays an integrated fallback design so the layout never breaks.*
